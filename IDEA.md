# Project Idea: IR Study Companion

## Overview
Interactive educational web platform for International Relations (IR Study Companion) built with a custom Bespoke LMS engine, Jekyll static site generator, 18 modules (157 lessons), and 10 interactive Diplomatic Simulation Labs.

## Key Components
- **Web Academy**: Modern Jekyll SSG with dark/light theme, active recall flashcards, quizzes, 18-module exams, and curated academic glossary.
- **Video Engine**: Canonical Mind Map Explanatory video production engine for official YouTube channel (`@IRinANutshell`) located in `simulation/ir-motion-library/` (Remotion + RoughJS + Kokoro-82M TTS + Patrick Hand font).
- **Quality Assurance**: Automated verification suite with 369/369 pytest tests and Playwright E2E testing.
